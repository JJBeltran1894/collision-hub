# Collision Hub

Crea una aplicación de gestión para un taller de colisiones llamada 'Centro de Colisiones'. \nEstablece una interfaz

responsiva con Tailwind CSS que simule un entorno híbrido:\n1. Una vista de Escritorio (PC) para Gerentes y

Contadores con barra de navegación lateral.\n2. Una vista optimizada para Móviles (PWA) para los Asesores en

Patio.\nConfigura una barra de navegación superior que permita alternar entre la vista 'Móvil (Asesor de Patio)' y

'Escritorio (Administración/Oficina)' con fines de simulación académica.\nUsa componentes de shadcn/ui y una paleta

de colores profesional (Slate y Deep Purple). Define la autenticación simulada con selección de Rol (Administrador,

Gerente, Asesor) y Sucursal (Quito Norte, Quito Sur, Guayaquil) para preparar el aislamiento de datos. - ten encuenta para este proyecto la guia de identidad
